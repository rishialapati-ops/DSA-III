# System Screenshots & Faculty Demonstration Guide

This directory holds documentation and visual guides for presenting the Alumni Connect KMP Pattern Search System:

1. **Dashboard Overview**: Primary search control, corpus status (100 documents), quick suggestions, and live search statistics.
2. **KMP Visualizer**: Step-by-step interactive pointer simulation showing text pointer $i$, pattern pointer $j$, LPS table reference, and mismatch fallback.
3. **Search Results Table**: Matching documents ranked by occurrence frequency, with metadata filters (department, graduation year, company) and highlighted inline snippets.
4. **Document Viewer**: High-fidelity inspect view of raw `.txt` files with safe markup rendering and exact occurrence locations.
5. **Corpus Explorer**: Directory browser displaying file attributes and previews for all 100 individual files (`alumni001.txt` to `alumni100.txt`).
6. **Complexity & Performance Comparison**: Side-by-side empirical comparison between KMP and naive pattern search algorithms across character comparison counts.
